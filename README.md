# Daily Reflection Tree Assignment

## Problem
This system helps users reflect on their daily challenges and provides structured guidance.

## Approach
A deterministic decision tree is used to guide users based on their inputs.

## Features
- Structured questioning
- Clear outputs
- No randomness

## Guardrails
- Invalid input is not accepted
- User must choose from given options
- No ambiguous outputs

## How it Works
User selects an issue → System asks follow-up questions → Final suggestion is provided
